# 八席权威宿主契约

`autopets.room_host` 将已经验证的连接身份映射到八席领域规则。它与双人宿主共用连接句柄的创建、撤销及恢复截止计算。原生平台的连接和界面能力另有 [八席技术样本](M3.md)。

| 宿主调用 | 成功返回值 |
| --- | --- |
| `host.new(seed, options)` | 宿主实例。沿用 `room.new` 选项，`reconnect_ms` 默认 15000。 |
| `host:connect(verified_player, now)` | 新连接句柄和下发帧。相同身份取得原席位，并撤销旧句柄。名单锁定后拒绝新身份。 |
| `host:request(connection, request, now)` | 接受标志、错误码和下发帧。沿用回合、序号和操作字段。 |
| `host:disconnect(connection, now)` | 成功标志和下发帧。候场失联会释放席位，局中失联会保留原席位至恢复截止。 |
| `host:leave(connection, now)` | 成功标志和下发帧。立即退出。 |
| `host:tick(now)` | 成功标志和下发帧。 |
| `host:next_deadline()` | 下一次阶段或恢复截止的单调毫秒时间戳，终局返回 `nil`。 |

外层宿主串行转发事件，按 `next_deadline()` 触发时钟。每帧包含 `{connection, state}`，只有对应连接可接收其商店、请求序号和回放。连接状态和排名由公开席位承载。接收方用单调递增的 `host_revision` 丢弃过期帧。成功的商店操作和重复、过期或非法请求只回复发起者。入席、连接变更、准备、结算及阶段推进更新所有在场连接。请求越过截止并改变公开状态时，即使请求被拒绝也会下发该状态。

接入方必须从可信连接上下文提供身份及句柄。临时断线时，对局时钟继续推进。同一身份可在时限内恢复当前状态。宿主按时序处理恢复与阶段截止。普通阶段截止与恢复到期同刻时，先移除全部到期席位。达到整局时限时立即定名次。若所有存活席同刻退出，按当时的生命、胜场和既定席位顺序定名次。域内已淘汰的身份仍可重新连接查看进度与自己的最终名次。真实千星玩家实体或 GUID 是否能支撑同身份恢复，以及实际断线和主动退出事件，仍需官方客户端确认。

使用 `lua5.4 -E tests/room_host.lua` 和 `lua5.3 -E tests/room_host.lua` 复验定向快照、句柄轮换、重试、主动退出、准备与恢复时限、同刻到期排名及真人离开后的机器人推进。

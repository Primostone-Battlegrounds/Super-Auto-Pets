## 开发基线

| 项目 | 开发基线 | 设计依据 |
| --- | --- | --- |
| 准备与交战 | 每轮先经营商店与排列阵容，再自动交战 | 项目产品定义采用 Arena 的轻量自动战斗体验。[项目产品定义](PRODUCT.md) [Steam 商店说明](https://store.steampowered.com/app/1714040/Super_Auto_Pets/#about) |
| 对手 | 回合、种子和流派决定本地 PvE 阵容 | 项目产品定义要求单人、可复现的流程。[项目产品定义](PRODUCT.md) |
| 终局 | 以 5 命开始，10 胜或零命结束；每次失败扣 1 命，平局维持胜数与命数 | 胜数和命数目标由项目产品定义确定；失败与平局的结算是本项目的开发规则。[项目产品定义](PRODUCT.md) |
| 阵型 | 五个从前到后排列的位置 | 五格阵容来自项目产品定义，前后顺序是本项目的战斗接口。[项目产品定义](PRODUCT.md) [项目架构](ARCHITECTURE.md) |
| 商店 | 每轮 10 金，3 个动物位、2 个食物位；刷新 1 金，购买动物或食物各 3 金；出售按每级 1 金返还 | 本项目的经济起点保留多次刷新或购买空间。[规则配置](../src/autopets/data.lua) |
| 解锁 | 第 1、3、5 轮分别解锁 1、2、3 阶，常规货架可抽取已解锁阶级 | 本项目三阶进度在前五轮逐步开放目录。[规则配置](../src/autopets/data.lua) |
| 成长 | 同名合成增加攻击和生命各 1 点，等级累计 XP 门槛为 0、2、5；升级提供一个额外原价动物，阶级为已解锁阶级加一且至多三阶 | 本项目让合成改善现有阵容并提前看见高阶选择。[规则配置](../src/autopets/data.lua) |
| 动物 | 正式名册按方案 B 选取。现有九种原创动物用于 G0 规则与对手流派回归 | 样板接入时沿用目录、阶级和流派接口，并验证商店与 PvE 对手使用的定义。见下方名册。[现有规则数据](../src/autopets/data.lua) |
| 食物 | 三阶共六种原创食物，永久调整目标的攻击或生命 | 攻防取向由食物数值表达，目录和名称由项目定义。[食物目录](../src/autopets/data.lua) |
| 召唤 | 三种由阵亡效果生成的原创单位，攻击随来源等级成长 | 公开货架目录由可买动物组成，召唤单位的数值独立定义。[召唤目录](../src/autopets/data.lua) |
| 表现 | 原神官方资料提供动物身份与视觉参考。技能文案、原生造型、图标和界面由本项目制作 | 生产步骤见 [原生美术工艺](ART_PIPELINE.md)。 |
| 里程碑版本 | G0 临时开发标识为 0.0.1-alpha.0；项目权威表的正式版本待读取 | 以项目权威表为准，访问仍受阻。[项目产品定义](PRODUCT.md) |

随机模块接受任意 Lua 5.4 有符号整数种子。零以及模数的倍数映射到状态 1。`next()` 返回 1 至 2147483646。`int(low, high)` 在含两端的整数范围内采样，范围内最多容纳 2147483646 个值，两端须落在 -2147483646 至 2147483646 之间。

## 动物与 SAP 机制映射

以下技能名称、图标说明与具体事件语义属于本项目设计。SAP 实现有版本差异，模板引用用于核对触发和战术职责。每级强度、每场次数、基础身材与阶位在样板回归时按本项目经济与对手曲线确定。[SAP 0.18 开发者更新](https://steamcommunity.com/games/1714040/announcements/detail/3217269675846591880/) · [SAP 机制索引](https://superautopets.wiki.gg/wiki/Pets)

| 动物 | 职责与 SAP 模板 | 本项目技能与身份表达 | 样板回归观察点 |
| --- | --- | --- | --- |
| 赤团雀 | 前期合成成长。Fish 的升级支援，直接映射 | **红羽报喜**。合成升到 2 或 3 级时，使最多两名随机的其他友方永久增加攻击与生命。在升阶鸣叫时显示红羽图标。 | 未升级的合成只结算常规合成收益。实际升阶额外执行一次，使用商店种子，无其他友方时正常完成合成。 |
| 水晶宴 | 买卖经济。Gold Fish 的售价积累，直接映射 | **奇纹溢价**。准备回合结束时给自己累积额外售价，下一轮仍有效，出售时一次性结清。用鳞纹闪光和售价变化表现收藏溢价。 | 持有一轮后结算一次，增量仅随出售入账。同种合成保留承接实例的售价记录，消耗副本的溢价不变现。 |
| 鬼兜虫 | 受伤触发。Peacock 的受击增攻，轻改编 | **顶角迎击**。战斗中受到实际伤害且存活时，自身本场增攻，按每场次数上限触发。图标取甲角，表现用短促抬角。 | 完全抵消和致死伤害均不增攻。多次有效命中到达上限后停触发，战斗结束清掉增益。 |
| 棘冠鳄 | 前排承伤。Turtle 的阵亡护后位，轻改编 | **棘背掩护**。战斗中阵亡时，给身后最近的存活友方施加本场一次性减伤。用棘背形护盾呈现保护。 | 后方空缺时找下一名存活友方。后方无人时跳过。保护消耗一次，任何未使用效果随战斗结束清除。 |
| 珊瑚蝶 | 站位辅助。Giraffe 的旧版回合结束定向养成，直接映射 | **珊翼回流**。准备回合结束时，让前方最近的存活友方获得永久攻防成长。用扇形翼纹与一束回流标记目标。 | 换位后受益者随之变化，空位可跨越，无前方目标时跳过。重复提交不得重算。 |
| 野林猪 | 中后期核心。Hippo 的击倒滚雪球，直接映射 | **连场冲锋**。战斗中由自身造成敌方阵亡且自身存活时，获得本场攻击与生命，表现为獠牙和短促尘线。 | 击倒归属正确，无归属或同归于尽时跳过。连续击倒可叠加，收益不回写商店阵容。 |

如需增加召唤、食物联动或后排爆发，先在名册中登记合适的官方动物，再复用对应已有事件。由同一事件在商店或战斗的结算时点统一处理状态，图标和动画消费结果。

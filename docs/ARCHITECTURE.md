# 架构

`src/autopets/` 保存纯 Lua 领域逻辑。目录提供模板和规则常量。商店持有持续阵容、货架和回合边界。战斗消费两个独立的前到后队伍快照及显式种子，产生可回放的结果和事件。单局控制器编排阶段、胜场和失败次数。

本地 AI 使用独立种子从空队开始。策略读取自身商店快照，提交玩家共用的商店命令。训练对局消费同轮快照，结算与进轮复用玩家规则。回放检查初始空队、命令、边界、战斗和状态摘要。

`autopets.duel` 为两个席位分别持有商店和生命。宿主传入已验证的玩家身份和单调毫秒时钟，按回合和席位序号接收操作。准备截止或双方锁定后，服务端复用同一战斗实例结算双方。两人确认或结算超时后开下一轮。每人的快照只带自己的商店和双方共用的已结算回放。

当前 1v1 规则候选可由宿主设置准备与结算时限和起始生命。默认 60 秒准备、10 秒结算、5 条命，败方扣 1 命，平局保留生命。千星运行时的身份、输入及回合同步由独立候选验证。[双人候选](../platform/M2.md)

千星 UI 把输入转换为领域指令，从快照和事件渲染。暂停、步进、跳过和菜单均由表现层管理。终端入口和 GIL 读回路径共享领域源码。

具体签名、状态所有权与验收分层见 [REASONS v1](design/REASONS-v1.md)。

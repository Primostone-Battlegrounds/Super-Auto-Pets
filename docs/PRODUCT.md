# 产品

《小动物自走棋》是千星奇域的轻量 2D 多人自走棋。玩家各自经营商店、培养五格阵容，每轮配对进行自动战斗。正式版主打 8 人淘汰赛，同时提供好友 1v1 和独立的单人 AI 练习。好友房间使用千星现有的邀请与入房能力。三种玩法从同一关卡的主菜单进入，里程碑用于研发验收。

| 正式版入口 | 优先级 | 首发范围 |
| --- | --- | --- |
| 八人吃鸡 | P0 | 核心玩法。至少一名真人即可开始，空席自动用机器人补满。 |
| 好友 1v1 | P0 | 两位好友各自经营，以权威自动战斗逐轮结算。 |
| 单人 AI 练习 | P1 | 入门和标准难度，完整商店、对局、回放和重开。 |
| 好友房间 | P1 | 通过平台支持的邀请与入房能力开始对局。 |

| 里程碑 | 功能与验收 |
| --- | --- |
| M1 | 单人练习可从商店、编队和自动战斗玩到结算及重开。官方 PC 和手机各完成整局，记录输入、文字、音效和性能。 |
| M2 | 两名好友各自经营并准备，服务端推进准备、对战和结算。先验证双设备身份和同步，再验收两台设备从开局到终局。 |
| M3 | 最多八席，真人入座，机器人补位。每轮两两配对，处理奇数存活、退出、扣血、淘汰和名次，并验收不同真人数量及平台匹配等待。 |
| M4 | 补齐六阶首发池、食物、技能时序和等级效果，扩充构筑与机器人策略。完成双端性能、匹配、多人同步和断线验证，交付 1v1、8 人淘汰赛和练习入口。 |

练习保留当前 10 胜、5 命和回放流程。机器人与真人共用商店和战斗规则。难度用经营决策、阵容协同和站位区分，使用固定种子与随机购物及不同策略做对抗比较。

首发沿用统一动物池。原神生物志用于内容研究，Standard 用于核对经济、技能触发和战斗结算。美术沿用项目原生控件与原创或已获授权的素材。历史兼容目录和覆盖记录见 [REASONS v1](design/REASONS-v1.md) 与 [Turtle 覆盖表](design/TURTLE-COVERAGE-v1.md)。

Arena 历史阵容、Daily、天梯、赛季和自定义动物包暂缓。里程碑版本由项目总表维护。验收证据按 [QA](QA.md) 记录。[项目总表](https://docs.google.com/spreadsheets/d/15V7Qj105fAavPajRsUhblu4KC3Zw72T9Q3iad2D6-M4/edit)

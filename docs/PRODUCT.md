# 产品

2026-11-23 正式采用方案 B。《小动物自走棋》是千星奇域的轻量 2D 单人 PvE 自走棋。动物身份以《原神》生物志和官方可核材料为准，玩法采用 Super Auto Pets 的商店经营、五格编队与自动战斗循环。对手由本地规则按种子、回合与流派生成。玩家从 5 命开始，10 胜或零命结束，终局可重开。[SAP 开发者商店页](https://store.steampowered.com/app/1714040/Super_Auto_Pets/#about)

## 核心循环

1. 每轮用有限金币购买、出售、刷新或冻结货架。食物和同种合成提供成长，升级奖励与商店解锁提供换阵机会。
2. 在五格里按前后顺序摆放动物，选择谁承伤、谁吃站位增益，以及何时转向新的流派。
3. 提交阵容后自动战斗，按胜、负、平结算并进入下一轮。落败扣 1 命，平局保留胜数和命数。

首轮验证沿用现有三阶解锁、经济与经验配置。动物的阶级、基础数值与技能成长按本地 PvE 节奏验证，保留原有购买、合成、食物及编队的取舍。单局无需联机，范围排除 PvP、匹配、天梯、跨局存档、原神人物战斗与角色技能系统。[开发基线](REFERENCE_MATRIX.md#开发基线)

## 动物与技能

- 选取官方可核的禽鸟、走兽、游鱼、昆虫或特殊小生物。每只动物记录中文名、类别、官方条目或游戏内定位、1–3 个外观识别点、1–3 个行为或生态印象，以及技能映射。
- 先找最强识别点并确定战术职责，再选 SAP 中最接近的机制。可沿用触发与战术作用，也可轻改触发、目标或表现，维持强度职责和编队取舍。技能名、文案、图标和反馈都从动物的外形或生态出发。
- [参照矩阵](REFERENCE_MATRIX.md) 管理名册和技能决策。首轮优先做赤团雀、水晶宴、鬼兜虫、棘冠鳄，分别检验成长、经济、受伤反应和前排保护。珊瑚蝶与野林猪分别补充辅助和中后期核心。

## 交付与验收

- G0 验证规则、工程入口和隔离的千星原生技术样本，并产出首轮四只可实例化的样板。
- M1 完成从商店到结算与重开的单局。在同一隔离候选中验证样板原生接入及 PC、手机表现。
- 原生美术沿用 [《杀戮原塔2》的生产工艺](ART_PIPELINE.md)。样板通过小尺寸图审、读回、释放和两端实机检查后，再扩下一小批。

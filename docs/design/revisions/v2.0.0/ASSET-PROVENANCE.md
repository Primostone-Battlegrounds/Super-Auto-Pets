# Asset provenance — v2.0.0

All creature art is original procedural SVG authored for this proposal in `prototype/index.html` (`art()`): Moss Deer, Cloud Fox, Stone Turtle, Dusk Owl and Sprout Hare. Geometric shapes, faces, foliage, antlers, shells and tails were drawn in code; no source tracing or imported artwork. Backgrounds, brand mark, badge, cards and controls are original CSS/SVG. All art remains editable in the source. No repository asset has been assumed licensed.

Typography uses the system sans-serif stack and optional Google Fonts Noto Sans SC (SIL Open Font License) via CSS; remote loading is optional and system fallback remains usable offline. Unicode decorative symbols are text glyphs rather than imported game art. No audio assets. Original source game screenshots live only in the separate research ledger and are not included in the prototype.

The five sample creature names, ability descriptions and stats are new illustrative copy, not approved release content. Production content identity and licensing require their own review.

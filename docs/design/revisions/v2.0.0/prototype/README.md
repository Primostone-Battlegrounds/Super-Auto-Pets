# Interactive local study

Serve this directory over HTTP and open `index.html` in a browser. For example: `python3 -m http.server 8765 --directory docs/design/revisions/v2.0.0/prototype`. This is a local deterministic study, not the Miliastra game or multiplayer simulator.

Automated smoke/scenario verification: `node docs/design/revisions/v2.0.0/prototype/verify-prototype.cjs`. Requires installed `playwright` and `/usr/bin/chromium`; uses a random loopback HTTP port and closes it at completion. Screenshots default to `/tmp/sap-prototype-evidence`; set `SAP_PROTOTYPE_EVIDENCE` to retain an independent evidence set. The test checks actual buttons and rendered state, including invite-before-start, direct and target-slot purchasing, reordered team, currency, freeze across refresh/round, battle speed/skip/result, end/restart, and sell. It checks horizontal overflow and Ready position in the 844×390 viewport. No account or internet access is needed for interactions; optional webfont falls back to the system font.

Read `../SPECIFICATION.md`, `../INTERACTIONS.md` and `../ACCEPTANCE.md` before interpreting captures. In particular, fixed victories, three-round completion, illustrative abilities and simulated invitations are deliberately labeled fixtures. Production/source-reuse gates remain open. An actual device playthrough and platform simulator cannot be replaced by this browser test.

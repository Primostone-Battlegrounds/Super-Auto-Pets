# 六阶首发命名与美术样板

范围为六阶各 10 只可购买动物，独立战斗召唤物及食物，覆盖练习、好友 1v1 和八人吃鸡的同一目录。命名使用中文通俗物种名和食物名。千星奇域提供承载和交互能力。现有虚构名称与旧图鉴保留在 v2.0.0 研发构建中，首发制作采用本次通俗命名与样板流程。

乌龟、兔子和猫咪的新肖像按各自的稳定动物 ID 接入三个模式。雨燕、麝和独角鲸显示各自的物种与现有技能。企鹅、长颈鹿和鲸鱼的早期画稿保留为设计记录。完整名册、阶级、技能数值和食物映射待确定。 [统一美术样板](../../../../platform/ART-PRACTICE.md)

从公开参考中记录亲和力、物种辨识、表情清晰和小画幅表现，采用原创剪影、姿态、配色与细节。设计稿与图元产物记录来源、参数、版本和散列。用同一源图做多个预算档，使用现有平台支持的素材和原生控件。 [原版官方参照](https://store.steampowered.com/app/1714040/Super_Auto_Pets/) · [原塔拟合与资源预算](https://github.com/FurinyaWorks/Slay-the-Heavens/blob/73c21489efaab409d4c0c46bee517d410d3427fc/docs/art/NATIVE_MONSTER_PRODUCTION.md)

经典 Turtle Pack 的构筑广度用于衡量养成、召唤、站位、伤害与生存等玩法。通用的五格编队、轮次商店、合成升级、确定性战斗、技能事件和结算沿用现有架构。原版同版轨迹与官方中文名尚无完整可核定证据，待确认规则与图鉴映射后再锁定内容设计。

当前草案记录首发方向和样板门禁。唯一生效的实现仍由清单绑定，批准的样板、映射与验收资产完成独立评审后再走版本激活流程。 [设计清单](../../manifest.json)

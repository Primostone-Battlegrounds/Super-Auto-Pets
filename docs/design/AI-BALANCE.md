# 六阶机器人离线对抗

机器人读自身商店快照，通过玩家共用的商店命令购买、合成、喂食、冻结、刷新、售出和调位。宿主负责提交命令、收轮和结算。两档策略从空阵开始，经过相同的金币预算和战斗引擎。

标准档评估技能效果和等级收益，为召唤配置后排支援，并在选择食物时计入相邻受益单位。阵型只在评分能提高时提交调位。入门档优先照顾较弱的队员，更少出售已有动物。三阶练习旧轨迹保持同一规则哈希和策略版本，六阶轨迹记录独立策略版本与目录哈希。

## 复验

```sh
lua5.4 scripts/audit-balance.lua release 256 > release-54.txt
lua5.3 scripts/audit-balance.lua release 256 > release-53.txt
cmp release-54.txt release-53.txt
sha256sum release-54.txt
```

种子 1–256 的 12 组对照均从空队开始。每组用相同的初始商店种子独立经营 12 轮，每轮用同一战斗种子交换双方位置，实际结算第一场并进入下一轮。每组共 6,144 场，共 73,728 场。随机策略优先填空位，随后从合法购买、合成和喂食中抽选，缺少可选操作时刷新。平局计半分。

标准档直接交战的得分率为防御对打击 52.8%、防御对召唤 53.0%、打击对召唤 51.1%。三种标准流派在随机对照的末轮共有 653 个不计站位的阵容，最常见组合出现 4/768 次。Lua 5.3.6 与 Lua 5.4.8 输出逐字节相同，SHA-256 为 `783b7caf846a0fe58319713379a8582588feed36dbf058affed214e81c8d097a`。

同一离线进程测量流程的墙钟时间分别为 28.083 秒和 29.874 秒（Lua 5.4、5.3 顺序），CPU 时间为 27.727 秒和 28.998 秒。Python `getrusage(RUSAGE_CHILDREN)` 记录的子进程最大 RSS 为 9,984 KiB。该测量对应成对商店和战斗循环。千星 PC、手机与八席宿主性能按各自验收环境采集。[验收规范](../QA.md)

# 八席对局离线负载

在领域对局提交 `b2a8392ec7db96fd4405f36d59a96007561d3901` 上，用本仓库脚本在每种真人席位数量下执行 64 个种子。真人席由测试驱动，通过房间请求入口经营，机器人在房间内从空阵容自主经营。测试还发送重复及跳号请求，并让指定席位在准备时限前保持未准备或中途退出。

```sh
lua5.4 -E scripts/audit-room.lua 64 > room-lua54.txt
lua5.3 -E scripts/audit-room.lua 64 > room-lua53.txt
cmp room-lua54.txt room-lua53.txt
sha256sum room-lua54.txt
```

标准输出只含确定性计数和回放摘要。两份输出逐字节一致，SHA-256 为 `1670b7b8333b1f784a27decd2e07cbba166639e597feca854cb2507f8f7efec7`。运行耗时和内存采样写入标准错误。

## 六阶内容与权威宿主

加上 `release host` 会启用六阶目录，测试驱动通过 `room_host` 认证、提交请求、接收定向帧并退出。下表统计宿主实际生成的帧，包括错误回执和公开阶段更新。每帧核对目标句柄和私有商店数据，仍无需平台网络。

```sh
lua5.4 -E scripts/audit-room.lua 32 release host > release-host-lua54.txt
lua5.3 -E scripts/audit-room.lua 32 release host > release-host-lua53.txt
cmp release-host-lua54.txt release-host-lua53.txt
sha256sum release-host-lua54.txt
```

两份确定性报告逐字节一致，SHA-256 `cf2d178dcb01f6b5aa4341a45cdbb1c14a985d5ec182571b49c6e173047763da`。256 局均由最后存活者取胜，包含 32 局一真人加七机器人，其间 1,054 场机器人互战。全组 4,386 回合，11,212 场战斗，其中 2,850 场为机器人互战。覆盖 1,550 次轮空、2,666 次未准备席位超时、36 次中途退出和 225 次同轮多席扣尽生命。最长单局 30 轮，模拟时钟累计 50.9 小时。

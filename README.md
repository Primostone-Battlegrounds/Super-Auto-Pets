# 小动物自走棋

千星奇域轻量 2D 单人 PvE 自走棋。经营商店、布置五格动物阵容，与按回合和种子生成的对手自动战斗。拿到 10 胜或耗尽 5 命时结算，终局可重开。

## 开发入口

- 在仓库根目录运行 `lua5.4 scripts/play.lua 7`，输入 `help` 查看操作。
- 安装 Backlog.md 1.53.0 后运行 `LUA=lua5.4 sh scripts/check.sh` 进行回归。
